command: man [command]

This is the command which will display all the details for a perticular command.

Now in this we will get a seperate page in the terminal and in that we can use different things to navigate it:

	/word: it can be use to search a perticular term in the page forword direction
	?word same but in the backword direction.

Now the man page itself have a structure:
	NAME: one line discription
	SYNOPSIS: how to call. [] means its optional, ... means repeatable, | means "or" (example of how to read the SYNOPSIS: {sort [OPTION]... [FILE]...} : this can be read as OPTION are optional and repeatable and FILE are also optional and repeatable)
	DISCRIPTION: how to use and list of option to use along with the command
	OPTION: flags explained
	EXAMPLE:not always present but useful
	EXIT STATUS: meaning of exit status returned.

In the man daatabase there are differet sectios related to different type of system calls these are numbered through 1 - 8

	1: use Command (ls, grep)
	2: System calls (open, fork)
	3: C library calls (printf, malloc)
	4: Special files/ device (/dev)
	5: File format and config files (passwd, fstab)
	6: Game and screensaver (usually empty)
	7: overview and concepts (man 7 hier (it will explain about the hirarchy of the file in thelinux system))
	8: Admin control (mount, ip)

For using the section in searchin of the command we use the flag -s [number]. (eg.: man -k -s 8 socket)


Command: man -k "[keyword]"  (eg.: man -k "open files")

This command will search the name and description for every command if that keyword is present in it and print the output. It is very useful for searching for commands for specific tasks


Command: man -f [command]

This is the command which givce a one line description for the command for which we already know the name of.


Command: [command] --help

This will give a short summary for that perticular command.

Some other useful tricks in man commands:
man -a [command] : show every matching page across section
man -w [command] : print the file path of the page 
man ls | grep -A2 -- -h : find a option fast witout opening the page
